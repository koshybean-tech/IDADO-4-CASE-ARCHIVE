# Idaho Case Archive

First working front-end foundation for a public, source-conscious Idaho case archive.

## Current version

- Responsive homepage
- Archive search and category/verification filters
- Archive record cards
- Timeline foundation
- People section foundation
- Separate Community section
- Public submission form (demo only)
- Administrator dashboard foundation (demo only)

## Important

This version is a static front end. The submission form does **not** upload files or create a real review queue yet. Before public use, connect secure authentication, a database, file storage, server-side validation, administrator permissions, moderation/reporting, audit logs, and backups.

## GitHub Pages

The site can be published from a public GitHub repository. Put `index.html`, `styles.css`, and `app.js` at the repository's top level, then configure GitHub Pages to deploy from the branch/folder you choose.
